# 2026 雙管奇下 ChiMeiRA

活動日期：2026-11-07。主場：資安暨智慧科技研發大樓 1 樓國際會議廳（臺南市歸仁區歸仁十三路一段 6 號）。

本專區新增在 CMQMweb 的 `chimeira-2026/`，不取代 2025 活動回顧。

## 活動與報名

- 院內、院外皆可報名上午論壇與一場平行工作坊。
- A 智慧抗生素管理／B 病人旅程與智慧品質照護／C 醫療安全 × AI，必須三選一。
- 依企劃書 30–40 人的規劃，各場先設定 40 名；後續收件列候補。
- 下午限三院區受邀核心成員；院內勾選後仍待主辦單位確認。
- 本一科技為協辦，奇美三院區品管與感管單位為主辦。
- 講者與講題仍為擬邀／規劃版本；費用、截止日及學分尚待主辦單位公告。

## 檔案

`index.html`、`styles.css`、`app.js`、`favicon.svg` 為靜態網站，可由現有 GitHub Pages 設定發布。

報名使用受保護的獨立收件服務，前台嵌入表單並提供獨立開啟連結：
https://chimeira-2026-registration.garytoh.chatgpt.site/

收件資料保存在服務的 D1 資料庫，不在公開 GitHub 儲存。

管理頁：
https://chimeira-2026-registration.garytoh.chatgpt.site/admin

管理員必須使用網站擁有者的 ChatGPT 帳號登入；後台會另外檢查服務端允許的管理員身分。可查看報名、匯出 CSV，並確認下午共識營受邀資格。CSV 具公式注入防護。未提供公開名單端點。

收件成功即顯示編號；系統不自動寄送 Email。候補安排與行前通知須由主辦單位另行處理。
